# 关注理由生成：接入 research.yaml

> 日期：2026-10-15
> 状态：用户已审核通过，实现及离线验证完成；未发布或重启服务。
> 单一目标：让现有“AI 生成建议”读取明确的研究入口与观点章节，替代目录名匹配和正文开头截取。

## 1. 已确认的问题与来源

当前 `web/services/watchlist_service.py::_research_excerpts` 只匹配股票代码同名目录，按文件名顺序读取顶层 Markdown，正文总预算约 6000 字符。因此 NBIS 无法关联中文目录，ORCL、INTC 的核心观点可能位于截取范围之外。

本机 `.env` 为 `STOCK_MARKETS=US`。研究库已只快进更新至 `d38e39fcbf9f582b64b73271a11f094f7cae041e`，包含 ORCL、NBIS、INTC、NAND 四个版本 2 入口。入口工具已证明章节定位可行，但尚未与本项目集成。研究库只作为内容来源；不执行其中脚本，不更改正文或入口文件，不将正文数值写入行情、财务表。

## 2. 本步完成后的行为

用户在现有看板点击“AI 生成建议”，系统按所选证券找到 `research.yaml`，读取其中指定的核心判断、风险、指标、待验证问题，交给现有模型生成可编辑草稿。不改变用户主动生成、审核和保存的流程。

- ORCL：读取主文档的“10. 我的看法”等明确章节，不读文章开头代替观点。
- NBIS：通过证券字段关联 `Nebius公司研究`，不要求目录改名为 NBIS。
- INTC：读取主文档的“7. 我的看法”等指定章节，不因专题文件排序而改变输入。
- NAND：仍是无证券的主题，不自动当作股票、不递归把相关主题正文加入公司提示词。

Pull 或重新生成不会自动覆盖已保存的分组、理由和研究链接；研究过不等于加入关注池或给出买卖指令。

## 3. 读取合同

新增独立研究读取模块，由现有 `suggest_fields(market, code, name)` 调用；使用 PyYAML 安全解析并拒绝重复键，补入项目依赖。独立实现必要的校验与 ATX 标题定位，不动态导入或运行研究库的校验脚本。

| 研究入口字段 | 消费端用途 |
|---|---|
| `schema_version` | 首版只接受 2；旧版或未知版本明确报错，不猜市场 |
| `entity_id` / `kind` | 稳定主体身份；股票查询只匹配 company |
| `securities[].market` / `mic` / `symbol` | 对应本项目 market / 交易所标识 / stock_code；代码始终作为字符串保留 |
| `primary_document` / `documents` | 主文档与允许引用的辅助文档，路径相对入口所在目录 |
| `sections.*.path` / `heading_path` | 定位实际标题祖先链，不匹配目录列表或代码块中的伪标题 |
| `related_entities` | 校验引用，不在本步展开关联正文 |

市场适配显式转换研究库 US/HK/CN 为本项目 US/CN_HK/CN_A，并校验市场与 MIC 组合。匹配同时使用市场与代码，多个候选返回歧义错误，不任取第一条。本机只做 US 样本验证；跨市场同代码和前导零以离线 fixture 测试，不访问国内数据库。

沿用 `STOCK_RESEARCH_REPO_PATH`。每次请求开始解析一个确定的 Git HEAD commit，并只读取该 commit 已跟踪的入口与 Markdown；不混入未提交文件，也不在请求中自动 pull。记录该 SHA，不能用文件修改时间或入口建立日期充当研究数据截止日。

拒绝绝对路径、仓库越界、符号链接及未声明文档引用；不存在的文件、非法 YAML、重复主体/证券、未知市场或非法 MIC 均明确报告。没有 research.yaml 的旧目录不再退回文件名猜测；兼容变化在文档中说明。

## 4. 摘录、错误与前端反馈

- `thesis`、`risks`、`metrics`、`open_questions` 分别保留独立片段，默认每类最多 1500 字符，正文总预算 6000；标注文件、章节起始行和是否截断，不让长主文档耗尽全部预算。
- 映射值为 null 属于“未配置”，可继续读取其他已配置章节并记录缺失项；已配置但标题找不到或匹配不唯一属于错误，停止生成，不退回通用草稿。
- 仓库不存在、Git 读取失败、入口损坏或读取异常时返回清楚的服务错误，且不调用模型。扫描发现入口错误时不把部分结果当作完整可用索引。
- 仓库与入口校验正常，但该证券确实没有入口时，保留现有 `[通用草稿]` 行为；若有入口却没有任何可用观点章节，则返回明确错误，不冒充基于研究生成。
- 保留返回字段 `group`、`note`、`source`、`docs`；可追加可选 `research` 诊断对象，携带主体 ID、来源 SHA、章节缺失/截断信息。前端仅在现有生成按钮旁补充必要提示，不新增研究页面。
- 提示词明确区分原文判断、风险和待验证问题；摘录视为研究材料而非指令，不执行文中操作，不把历史研究当作当前已验证事实。

正文摘录仍按现有功能发送给 MiniMax；本步不增加模型供应商、自动调用或定时发送，不在测试中发出真实模型请求。敏感研究应由用户评估是否适合使用该按钮。
