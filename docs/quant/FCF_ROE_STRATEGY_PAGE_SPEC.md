# FCF+ROE 深度价值策略页面规格

## 目标与范围

为 `FCF+ROE 深度价值` 建立独立页面，让投资者可以在不改变策略核心定义的前提下调整估值与盈利能力门槛、查看筛选结果和数据时点。

本页只服务该策略；不复用通用筛选页的“任意预设”入口。初版不包含下单、持仓管理或回测功能。

## 策略定义

策略先做硬过滤，再按既有权重排序：FCF Yield 30%、CFO 质量 25%、PB 20%、营收同比 15%、毛利率 10%。

以下规则为固定规则，不向用户提供关闭开关：

| 规则 | 定义 |
| --- | --- |
| 金融行业排除 | A 股：银行、非银金融、房地产；港股：银行、保险、其他金融、地产；美股：银行、保险、券商、REIT、投资顾问及其他金融 SIC 行业。 |
| ST 排除 | A 股/港股排除名称含 `ST` 或 `*ST` 的证券。 |
| ROE 连续性 | 最近连续 3 个年度报告期的 ROE 必须均不低于用户设定的 ROE 下限；缺失任一年度即不通过。 |
| 数据完整性 | 市值、FCF Yield、当期 ROE 缺失即不通过相应硬过滤。 |

## 可调参数与默认值

页面应按市场显示默认值；用户修改后只对本次查询生效，可提供“恢复默认”按钮。

| 参数 | 控件 | US 默认值 | CN_A / CN_HK 默认值 | 校验 |
| --- | --- | ---: | ---: | --- |
| 市场 | 单选：US、CN_A、CN_HK | US | 当前选择的市场 | 必填；服务端仅接受单一市场。 |
| 最低市值 | 数值输入 + 单位选择 | 20 亿美元 | 50 亿元/港元 | `> 0`。 |
| 最低 FCF Yield | 百分比数值输入 | 10% | 12% | `0%–100%`。 |
| 最低 ROE | 百分比数值输入 | 12% | 12% | `0%–100%`。 |
| 显示数量 | 数值输入/下拉 | 30 | 30 | 整数 `1–100`。 |

“连续 3 年 ROE”在界面上应显式展示为固定条件，而不是隐藏在说明中。

## 页面结构

1. 标题区：策略名称、简短定义，以及“固定排除金融类”的醒目标签。
2. 参数面板：上述可调参数、恢复默认、运行筛选按钮。
3. 结果摘要：全市场候选数、硬过滤后数量、最终显示数量、实际生效参数和查询时间。
4. 结果表：排名、代码、名称、行业、市值、FCF Yield、当期/前一年/前两年 ROE、PB、PE、综合分数。
5. 数据提示：每只股票显示 TTM 财报截止日；超过 180 天的 FCF 数据显示“数据过时”，不能静默隐藏。
6. 空状态与错误：没有结果时说明哪个阈值组合导致无结果；接口失败时显示明确错误及重试按钮。

默认按综合分数升序。FCF Yield、ROE、市值和 PB 应支持本地排序；点击代码或名称进入现有个股分析页。

## 后端接口建议

保留现有通用接口以兼容旧页面，并新增策略专用接口：

```http
POST /api/v1/strategies/fcf-roe/run
Content-Type: application/json

{
  "market": "US",
  "market_cap_min": 2000000000,
  "fcf_yield_min": 0.10,
  "roe_min": 0.12,
  "top_n": 30
}
```

服务端必须从 `fcf_roe_value` 的固定配置复制权重、金融行业排除和“连续 3 年 ROE”规则，只覆盖请求中明确允许调整的 4 个字段。禁止让客户端传入 `exclude_industries`、`weights` 或 `roe_consecutive_years`，以免改变策略定义。

响应应包含 `applied_filters`、`fixed_rules`、`total_before_filter`、`total_after_filter`、`results` 和每只股票的 `ttm_report_date` / `stale_warning`。金额均保持原始货币数值，并返回 `currency` 供前端格式化。

## 验收标准

- 默认 US 查询与现有 `fcf_roe_value` 的规则一致，但不返回任何金融 SIC 行业股票。
- 调高任一阈值只会减少或保持结果数量，绝不增加结果数量。
- 任意金融行业股票即使 FCF Yield、ROE 和市值满足要求，也不会出现在结果中。
- ROE 最近三年中有缺失或任一年低于阈值的股票不会出现。
- FCF 数据超过 180 天时，结果表明确显示过时提示。
- 前端传入非法阈值或不支持市场时，接口返回明确的 `400` 错误。
